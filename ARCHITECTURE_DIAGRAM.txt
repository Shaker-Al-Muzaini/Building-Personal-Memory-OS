                       INTERACTION EXAMPLE

📝 Scenario: User يريد إنشاء فكرة جديدة

1. User يضغط "Create Idea" ← UI
2. HTTP POST /ideas/store → IdeaController@store ← Presentation
3. Controller تستدعي CreateIdeaUseCase@execute ← Application
4. Use Case:
   a. تستدعي AIService لتحليل الفكرة ← Infrastructure
   b. تنشئ Idea Entity مع البيانات ← Domain
   c. تستدعي IdeaRepository@create ← Domain Contract
5. IdeaRepository (الإنسان في Infrastructure):
   a. ترسل Idea Entity إلى قاعدة البيانات ← Database
   b. أرجع الـ ID الجديد للـ Entity
6. Use Case ترجع الـ Idea Entity حفظت بنجاح برجوع Controller
7. Controller يرجع response للـ User ← Presentation
